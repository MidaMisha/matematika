Решение иррациональных уравнений и неравенств

Главная цель темы — научиться правильно избавляться от корней, не получать лишние корни и уверенно решать типовые задания экзамена.

1. Что называется иррациональным уравнением

Иррациональное уравнение — это уравнение, в котором неизвестная находится под знаком корня или в дробной степени.

√(x + 5) = x − 1
∛(2x − 3) = 5
⁴√x + ⁸√x = 2

Основная идея решения: избавиться от корня. Для квадратного, четвёртого и других корней чётной степени обязательно учитывают область допустимых значений и знак правой части.

Важно. Возведение обеих частей уравнения в квадрат может дать посторонние корни. Поэтому либо заранее выписываем условия равносильности, либо обязательно проверяем найденные значения в исходном уравнении.

2. Что нужно помнить о корнях

ВыражениеУсловие
√AA ≥ 0
1√AA > 0
⁴√A, ⁶√A и т. д.A ≥ 0
∛A, ⁵√A и другие корни нечётной степениA может быть любым действительным числом

Корень чётной степени всегда принимает неотрицательное значение:

√A ≥ 0, если A ≥ 0.

Именно поэтому из уравнения √A = B следует, что обязательно B ≥ 0.

3. Главный тип: √A = B

Алгоритм:
  1. Потребовать B ≥ 0.
  2. Возвести обе части в квадрат.
  3. Решить полученное уравнение.
  4. Проверить условия и ответ.
√A = B   ⇔   A = B²,   B ≥ 0.

Пример 1

Решить: √(x + 1) = x − 1.

1. Правая часть должна быть неотрицательной:

x − 1 ≥ 0 ⇒ x ≥ 1.

2. Возводим в квадрат:

x + 1 = (x − 1)².

x + 1 = x² − 2x + 1.

x² − 3x = 0.

x(x − 3) = 0.

x = 0 или x = 3.

3. Условию x ≥ 1 подходит только x = 3.

Ответ: 3.

4. Если корни стоят в обеих частях

Тип √A = √B

Оба выражения должны существовать, после чего можно сравнить подкоренные выражения:

√A = √B   ⇔   A = B, при A ≥ 0 и B ≥ 0.

Пример 2

√(2x + 3) = √(x + 8)

2x + 3 = x + 8 ⇒ x = 5.

Проверка ОДЗ: обе части определены.

Ответ: 5.

5. Уравнения, где приходится возводить в квадрат два раза

Если в уравнении несколько квадратных корней, один корень обычно изолируют, затем возводят в квадрат. Если корень остался — повторяют.

Пример 3

√(x + 4) + √x = 4.

ОДЗ: x ≥ 0.

Оставим один корень слева:

√(x + 4) = 4 − √x.

Правая часть должна быть ≥ 0.

Возводим в квадрат:

x + 4 = 16 − 8√x + x.

8√x = 12.

√x = 32.

x = 94.

Проверка показывает, что значение подходит.

Ответ: 9/4.

6. Корни разных степеней. Замена переменной

Если встречаются степени или корни, связанные между собой, часто удобно ввести новую переменную.

Если одновременно есть ⁴√x и ⁸√x, удобно положить t = ⁸√x. Тогда t ≥ 0, а ⁴√x = t².

После замены получается обычное квадратное уравнение. В конце обязательно возвращаемся к переменной x.

7. Корни нечётной степени

Для кубического, пятого и других корней нечётной степени ситуация проще: их подкоренное выражение может быть отрицательным.

∛A = B   ⇔   A = B³.

Пример 4

∛(2x − 1) = 3.

2x − 1 = 27.

2x = 28.

x = 14.

8. Иррациональные неравенства

В неравенствах главная сложность — нельзя просто возвести обе части в квадрат, не посмотрев на их знаки.

Тип √A ≤ B

√A ≤ B   ⇔   A ≥ 0,   B ≥ 0,   A ≤ B².

Тип √A < B

√A < B   ⇔   A ≥ 0,   B > 0,   A < B².

Пример 5

√(x + 1) ≤ 3.

ОДЗ: x + 1 ≥ 0 ⇒ x ≥ −1.

Правая часть положительна, поэтому возводим в квадрат:

x + 1 ≤ 9 ⇒ x ≤ 8.

Пересекаем условия:

Ответ: [−1; 8].

9. Неравенства √A > B и √A ≥ B

Здесь удобно рассматривать знак правой части.

Если B < 0, то √A ≥ 0 автоматически больше B. Остаётся только ОДЗ.

Если B ≥ 0, можно возвести обе части в квадрат и сравнить A и B².

Пример 6

√(2x − 1) > x − 2.

ОДЗ: 2x − 1 ≥ 0 ⇒ x ≥ 1/2.

1 случай: x − 2 < 0 ⇒ x < 2.

Тогда неравенство выполняется автоматически:

x ∈ [1/2; 2).

2 случай: x − 2 ≥ 0 ⇒ x ≥ 2.

Возводим в квадрат:

2x − 1 > (x − 2)².

2x − 1 > x² − 4x + 4.

x² − 6x + 5 < 0.

(x − 1)(x − 5) < 0.

1 < x < 5.

С учётом x ≥ 2 получаем [2; 5).

Объединяем два случая.

Ответ: [1/2; 5).

10. Сравнение двух корней

Если обе части — квадратные корни, они неотрицательны. После ОДЗ можно сравнивать подкоренные выражения.

√A ≤ √B   ⇔   A ≤ B, при A ≥ 0 и B ≥ 0.

Пример 7

√(x + 3) ≥ √(2x − 1).

ОДЗ: x + 3 ≥ 0 и 2x − 1 ≥ 0 ⇒ x ≥ 1/2.

Сравниваем подкоренные выражения:

x + 3 ≥ 2x − 1.

x ≤ 4.

Ответ: [1/2; 4].

11. Частые ошибки

  • Забыли ОДЗ. Например, √(x − 2) существует только при x ≥ 2.
  • Не проверили знак правой части. Уравнение √A = B не имеет решений там, где B < 0.
  • После возведения в квадрат приняли все корни. Квадратирование может дать посторонний корень.
  • Неправильно возвели двучлен в квадрат: (a − b)² = a² − 2ab + b².
  • Забыли вернуться к x после замены t = ⁸√x.
  • В неравенстве возвели в квадрат части неизвестного знака.

12. Короткая памятка-алгоритм

  1. Найти ОДЗ.
  2. Изолировать один корень.
  3. Проверить знак второй части, если корень чётной степени.
  4. Возвести обе части в нужную степень.
  5. Решить полученное рациональное уравнение или неравенство.
  6. Если корень остался — повторить.
  7. Проверить найденные корни в исходном уравнении.
  8. Записать окончательный ответ.

13. Задание из экзамена

а) Решить уравнение

√(34 − 3x) = x − 2.

Шаг 1. Условия.

Так как квадратный корень неотрицателен, правая часть должна быть неотрицательной:

x − 2 ≥ 0 ⇒ x ≥ 2.

Также 34 − 3x ≥ 0 ⇒ x ≤ 34/3.

Шаг 2. Возводим в квадрат:

34 − 3x = (x − 2)².

34 − 3x = x² − 4x + 4.

x² − x − 30 = 0.

(x − 6)(x + 5) = 0.

x = 6 или x = −5.

Шаг 3. Отбор.

x = −5 не подходит условию x ≥ 2.

Проверка x = 6:

√(34 − 18) = 6 − 2 ⇒ √16 = 4 ⇒ 4 = 4.

Ответ: x = 6.

б) Решить уравнение

⁴√x + ⁸√x − 2 = 0.

Шаг 1. ОДЗ: x ≥ 0.

Шаг 2. Замена переменной.

Пусть t = ⁸√x. Тогда t ≥ 0.

Так как ⁴√x = (⁸√x)², получаем:

t² + t − 2 = 0.

Шаг 3. Решаем квадратное уравнение:

(t − 1)(t + 2) = 0.

t = 1 или t = −2.

Но t ≥ 0, поэтому t = −2 не подходит.

Шаг 4. Возвращаемся к x:

⁸√x = 1 ⇒ x = 1.

Проверка:

⁴√1 + ⁸√1 − 2 = 1 + 1 − 2 = 0.

Ответ: x = 1.

14. Что обязательно уметь к экзамену

  • находить ОДЗ выражений с корнями;
  • решать уравнения вида √A = B;
  • решать уравнения с двумя квадратными корнями;
  • использовать замену переменной для корней разных степеней;
  • решать простейшие иррациональные неравенства;
  • правильно учитывать знак правой части;
  • проверять корни после возведения в квадрат.
