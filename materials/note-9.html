1. Числа, дроби и проценты

Смешанное число переведите в неправильную дробь. Для сложения нужен общий знаменатель; для деления — обратная дробь. Например, 20 : 1 ⅔ = 20 · 3/5 = 12.

Для сравнения положительных дробей a/b и c/d при b, d > 0 сравните ad и bc. Например, 5/8 < 7/10, так как 50 < 56.

При сравнении неотрицательных чисел можно сравнить их квадраты: 2,6 < √7, потому что 6,76 < 7. Поэтому 5/2 < 2,6 < √7.

p% числа A равны A · p/100. Например, 16% от 125 = 20.

2. Формулы сокращённого умножения

(a + b)² = a² + 2ab + b²
(a − b)² = a² − 2ab + b²
a² − b² = (a − b)(a + b)

(3x − 2y)² = 9x² − 12xy + 4y².

(x² − 16)/(x + 4) = x − 4, но только при x ≠ −4.

Сокращают множители, а не отдельные слагаемые. ОДЗ исходной дроби сохраняется после сокращения.

3. Деление алгебраических дробей

Запишите ограничения: знаменатели не равны нулю, а дробь-делитель не равна нулю. Затем замените деление умножением на обратную дробь и разложите выражения на множители.

[6x²/(a² − b²)] : [2x/(a − b)].

ОДЗ: a ≠ b, a ≠ −b, x ≠ 0.

6x²/[(a − b)(a + b)] · (a − b)/(2x) = 3x/(a + b).

(x²/y² − x/y) : ((x − y)/y²).

ОДЗ: y ≠ 0, x ≠ y.

Первая скобка равна x(x − y)/y². Делим на (x − y)/y² и получаем x с прежними ограничениями.

4. Уравнения и системы

Линейные: раскрыть скобки → собрать неизвестные → разделить на ненулевой коэффициент.

Квадратные: привести к ax² + bx + c = 0 → D = b² − 4ac → x = (−b ± √D)/(2a) при D ≥ 0.

Дробно-рациональные: ОДЗ → общий знаменатель → решение → отбор корней.

В системах используйте подстановку или сложение. Ответ записывайте парой (x; y), проверяя оба уравнения.

5. Неравенства и область определения

При делении на отрицательное число знак неравенства переворачивается. Для произведений и дробей используйте метод интервалов.

В области определения рациональной функции исключают нули знаменателя. У квадратного корня подкоренное выражение должно быть ≥ 0. Если корень находится в знаменателе, оно должно быть > 0.

y = (x² − 1)/(x² − 25). Ограничение: x² − 25 ≠ 0 → x ≠ ±5.

y = √(x − 4)/(x − 6). Нужно x ≥ 4 и x ≠ 6.

Область определения: [4; 6) ∪ (6; +∞).

6. Проверка перед сдачей

  • Все ли ограничения выписаны до сокращения?
  • Учтён ли минус перед скобками и дробями?
  • Не потерян ли нулевой корень?
  • Верно ли выбраны круглые и квадратные скобки?
  • Есть ли окончательный ответ, а не только вычисления?

Если забыли способ, вернитесь к конспекту соответствующей темы: там есть пошаговые примеры.
