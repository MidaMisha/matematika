1. Равносильные преобразования

Корень уравнения — значение неизвестного, при котором получается верное равенство. Можно прибавить к обеим частям одно выражение, раскрыть скобки, привести подобные слагаемые. Умножать и делить обе части на одно число можно, если оно не равно нулю.

При переносе слагаемого через знак равенства меняется его знак. Деление на выражение с неизвестным может потерять корни: сначала проверьте, когда оно равно нулю.

2. Линейное уравнение

Приведите уравнение к виду ax = b. При a ≠ 0 ответ x = b/a.

3(2x − 5) = 2x + 9.

6x − 15 = 2x + 9 → 4x = 24 → x = 6.

Проверка: 3 · (12 − 5) = 21; 12 + 9 = 21.

Если получили 0x = 0, подходят все допустимые значения x. Если получили 0x = 5, решений нет.

3. Уравнение с числовыми знаменателями

Умножьте каждое слагаемое обеих частей на НОК знаменателей. Скобки вокруг числителей сохраняйте до раскрытия.

(x − 1)/3 + (x + 2)/4 = 4.

Умножаем всё на 12: 4(x − 1) + 3(x + 2) = 48.

4x − 4 + 3x + 6 = 48 → 7x = 46 → x = 46/7.

Множитель относится также к правой части и к целым слагаемым.

4. ОДЗ дробно-рационального уравнения

Область допустимых значений (ОДЗ) — все значения, при которых исходное выражение определено. У дробей каждый знаменатель должен быть отличен от нуля. Запишите ограничения до сокращения.

(x + 5)/(x − 3) = 3. ОДЗ: x ≠ 3.

Умножаем на x − 3: x + 5 = 3(x − 3).

x + 5 = 3x − 9 → 2x = 14 → x = 7.

7 ≠ 3, значит корень подходит. Проверка: 12/4 = 3.

5. Общий знаменатель и несколько дробей

Разложите знаменатели на множители, найдите общий знаменатель и умножьте на него все слагаемые. На ОДЗ этот знаменатель ненулевой.

(2x + 3)/(x − 2) − (x − 1)/(x − 2) = 3, x ≠ 2.

2x + 3 − (x − 1) = 3(x − 2).

x + 4 = 3x − 6 → x = 5. Ограничение выполнено.

1/(x − 1) + 1/(x + 1) = 4/(x² − 1), x ≠ ±1.

x² − 1 = (x − 1)(x + 1).

x + 1 + x − 1 = 4 → 2x = 4 → x = 2.

Минус перед дробью меняет знаки всех слагаемых её числителя.

6. Посторонний корень и тождество

Запрещённое значение.

(x² − 9)/(x − 3) = 6, x ≠ 3.

На ОДЗ сокращаем: x + 3 = 6 → x = 3. Но он запрещён. Ответ: решений нет.

Бесконечно много решений.

(2x − 4)/(x − 2) = 2, x ≠ 2.

После сокращения получается 2 = 2. Ответ: все действительные x, кроме 2.

Если после преобразований получилось неверное числовое равенство, решений нет независимо от ОДЗ.

7. Памятка

  1. Записать ОДЗ.
  2. Разложить знаменатели и найти общий.
  3. Умножить обе части на общий знаменатель.
  4. Решить полученное уравнение.
  5. Отбросить корни, нарушающие ОДЗ; проверить ответ подстановкой.
