Логарифм числа

Определение логарифма, переход между показательной и логарифмической формами, основное логарифмическое тождество, десятичный и натуральный логарифмы.

1. Определение логарифма

Логарифмом положительного числа b по основанию a называется показатель степени, в которую нужно возвести a, чтобы получить b.

logab = c ⇔ ac = b.
Обязательные условия: a > 0,   a ≠ 1,   b > 0.

В записи logab число a — основание, число b — аргумент.

Пример 1. log28 = 3, потому что 23 = 8.

3. Переход к показательной форме

Чтобы вычислить логарифм, замените логарифмическую запись равносильной показательной.

Пример 2. log5125 = x ⇔ 5x = 125 = 53.
Ответ: 3.
Пример 3. log2(1/16) = x ⇔ 2x = 1/16 = 2−4.
Ответ: −4.

4. Переход от степени к логарифму

ac = b ⇔ logab = c.
Пример 4. 34 = 81 ⇔ log381 = 4.
Пример 5. 91/2 = 3 ⇔ log93 = 1/2.

5. Простейшие значения логарифмов

loga1 = 0, потому что a0 = 1.
logaa = 1, потому что a1 = a.

6. Логарифмические уравнения по определению

Если неизвестен аргумент, перейдите к показательной форме и обязательно проверьте, что аргумент положителен.

Пример 6. log3(x − 1) = 2.
x − 1 = 32;   x = 10. Условие x − 1 > 0 выполнено.
Ответ: 10.
Пример 7. log9x2 = 1.
x2 = 9;   x = −3 или x = 3. При обоих значениях x2 > 0.
Ответ: −3; 3.

7. Если неизвестно основание

Основание логарифма должно удовлетворять условиям a > 0 и a ≠ 1.

Пример 8. logx64 = 3.
x3 = 64;   x = 4. Условия для основания выполнены.
Ответ: 4.
Пример 9. logx(1/8) = −3.
x−3 = 1/8;   1/x3 = 1/8;   x = 2.
Ответ: 2.

8. Основное логарифмическое тождество

alogab = b,   где a > 0, a ≠ 1, b > 0.
loga(ax) = x.
Пример 10. 2log27 = 7.
Пример 11. log5(5−3) = −3.

9. Десятичный логарифм

Логарифм по основанию 10 записывают без основания:

lg b = log10b.
Пример 12. lg 1000 = 3, потому что 103 = 1000.
Пример 13. lg 0,01 = −2, потому что 10−2 = 0,01.

10. Натуральный логарифм и число e

Число e ≈ 2,71828. Логарифм по основанию e называется натуральным и обозначается ln.

ln b = logeb.
Пример 14. ln e4 = 4.
Пример 15. eln 6 = 6.

11. Алгоритм вычисления логарифма

  1. Проверить условия существования логарифма.
  2. Обозначить значение логарифма буквой, например x.
  3. Перейти к показательной форме.
  4. Представить аргумент в виде степени основания.
  5. Сравнить показатели и записать ответ.

12. Частые ошибки

  • путают основание и аргумент;
  • допускают основание 1, 0 или отрицательное число;
  • пытаются найти логарифм нуля или отрицательного числа;
  • забывают знак «минус» при логарифме правильной дроби по основанию больше 1;
  • не проверяют условия для неизвестного основания или аргумента.
Пока не используем формулы логарифма произведения, частного и степени. Они относятся к следующей теме «Свойства логарифмов».
