Показательные неравенства

Сравнение степеней, приведение к одному основанию, вынесение общего множителя и замена переменной.

1. Что называется показательным неравенством

Показательным называется неравенство, в котором неизвестная находится в показателе степени.

2x > 8;   32x−1 ≤ 27;   4x − 5·2x + 4 > 0.

Основой решения служит монотонность функции y = ax.

2. Главное правило

ОснованиеПоведение функцииКак сравнивать показатели
a > 1Функция возрастаетЗнак неравенства сохраняется
0 < a < 1Функция убываетЗнак неравенства меняется
a > 1:   af(x) > ag(x) ⇔ f(x) > g(x).
0 < a < 1:   af(x) > ag(x) ⇔ f(x) < g(x).
Главная ошибка: забыть поменять знак при основании между 0 и 1.

3. Одинаковые основания

Пример 1. 52x−1 ≤ 5x+3.
Основание 5 > 1, поэтому знак сохраняется:
2x − 1 ≤ x + 3;   x ≤ 4.
Ответ: (−∞; 4].
Пример 2. (1/3)2x+1 > (1/3)7−x.
Основание 1/3 находится между 0 и 1, поэтому знак меняется:
2x + 1 < 7 − x;   3x < 6;   x < 2.
Ответ: (−∞; 2).

4. Приведение к одному основанию

Используйте представления 4 = 22, 8 = 23, 16 = 24, 9 = 32, 27 = 33, 81 = 34.
Пример 3. 4x+1 > 8x−1.
22x+2 > 23x−3.
2x + 2 > 3x − 3;   x < 5.
Ответ: (−∞; 5).

5. Сравнение с единицей

Единицу удобно записывать как a0.

Пример 4. 3x²−5x+6 ≤ 1.
1 = 30, а 3 > 1:
x² − 5x + 6 ≤ 0.
(x − 2)(x − 3) ≤ 0.
Ответ: [2; 3].
Пример 5. (1/2)x−4 > 1.
1 = (1/2)0. Основание меньше 1, поэтому x − 4 < 0.
Ответ: (−∞; 4).

6. Вынесение общей степени

Пример 6. 2x+1 + 2x > 24.
2·2x + 2x > 24.
3·2x > 24;   2x > 8 = 23.
Ответ: (3; +∞).

7. Замена переменной

Если встречаются a2x и ax, вводят замену t = ax. Всегда учитывают условие t > 0.

Пример 7. 4x − 5·2x + 4 > 0.
Пусть t = 2x, t > 0. Тогда 4x = t2.
t2 − 5t + 4 > 0;   (t − 1)(t − 4) > 0.
С учётом t > 0: 0 < t < 1 или t > 4.
2x < 1 ⇒ x < 0;   2x > 4 ⇒ x > 2.
Ответ: (−∞; 0) ∪ (2; +∞).

8. Однородные неравенства

Если присутствуют степени вида a2x, (ab)x и b2x, делят на одну из положительных степеней.

Пример 8. 2·9x − 5·6x + 3·4x ≥ 0.
Делим на 4x > 0 и полагаем t = (3/2)x:
2t2 − 5t + 3 ≥ 0;   (2t − 3)(t − 1) ≥ 0.
0 < t ≤ 1 или t ≥ 3/2.
Ответ: (−∞; 0] ∪ [1; +∞).

9. Алгоритм решения

  1. Упростить степени и попытаться получить одинаковые основания.
  2. Определить: основание больше 1 или находится между 0 и 1.
  3. При одинаковых основаниях сравнить показатели.
  4. Если есть общий множитель, вынести степень.
  5. Если выражение квадратное относительно ax, ввести t = ax, t > 0.
  6. Решить обычное неравенство относительно t.
  7. Вернуться к x, используя монотонность показательной функции.

10. Частые ошибки

  • не меняют знак при основании 0 < a < 1;
  • сравнивают показатели при разных основаниях;
  • забывают условие t > 0 при замене;
  • делят на выражение, не проверив его знак;
  • теряют граничные точки при знаках ≥ и ≤.
