Практика №12. Показательные уравнения

Приведение к одному основанию, уравнивание показателей и вынесение общей степени.

1. Уравняйте показатели

1. 2x = 25.
2. 73x−2 = 710.
3. 52x+1 = 5x+7.
4. 3x2 = 34x−3.
5. (1/4)2x−1 = (1/4)5−x.
6. 0,2x2−6x = 0,2−8.
7. 11|x−2| = 113.
8. 6x2−1 = 62x+2.

2. Приведите к одному основанию

9. 4x = 26.
10. 8x−1 = 16.
11. 27x = 9x+2.
12. 252x−1 = 125x−2.
13. 32x+1 = 82x−1.
14. 0,125x = 41−x.
15. (1/9)x−2 = 271−2x.
16. 49x+1 = (1/7)3−x.

3. Используйте свойства степеней

17. 2x · 4x = 64.
18. 9x : 3x−1 = 81.
19. 5x+2 : 25x−1 = 125.
20. 4x · 81−x = 2.
21. 32x−1 · 9x+1 = 273.
22. 16x−1 : 8x−2 = 32.
23. (2x+1)2 = 8x.
24. 9x · 27x = 325.

4. Вынесите общую степень

25. 2x+1 + 2x = 48.
26. 3x+2 − 3x = 72.
27. 5x + 5x−1 = 30.
28. 7x+1 − 6 · 7x = 49.
29. 4x + 2 · 4x−1 = 96.
30. 2 · 3x+1 + 3x−1 = 57.
31. 5x+1 − 4 · 5x−1 = 105.
32. 2x+3 + 2x+1 − 2x = 36.
