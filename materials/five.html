Практика №5. Линейные, квадратные и дробно-рациональные неравенства

Решите линейные неравенства

  1. 3x − 7 > 11
  2. 5x + 4 ≤ 19
  3. 8 − 2x > 14
  4. 7x − 9 ≥ 3x + 15
  5. 4 − 5x < 2x + 18
  6. 6(x − 2) ≤ 3x + 9
  7. 4(2x + 1) > 5x − 8
  8. 3(x − 4) + 2 ≥ 2(x + 5)

Решите методом интервалов

  1. (x − 4)(x − 1)(x + 3) > 0
  2. (x + 5)(x + 2)(x − 3)(x − 6) ≤ 0
  3. x(x − 2)(x + 1)(x + 4) ≥ 0
  4. (2x − 1)(x + 3)(x − 5) < 0

Решите квадратные неравенства

  1. x² − 5x + 6 > 0
  2. x² − 7x + 12 ≤ 0
  3. x² + x − 6 < 0
  4. x² − 9 ≥ 0
  5. 2x² − 5x − 3 > 0
  6. 3x² + x − 2 ≤ 0
  7. 4x² − 4x − 3 < 0
  8. 6x² − 13x + 6 ≥ 0
  9. −x² + 6x − 8 > 0
  10. −2x² + 3x + 2 ≤ 0

Решите дробно-рациональные неравенства

  1. x − 3x + 2 > 0
  2. x + 4x − 1 ≤ 0
  3. 2x − 5x + 3 ≥ 0
  4. 3 − xx − 2 < 0
  5. (x − 2)(x + 5)x − 1 > 0
  6. (x + 3)(x − 4)x + 1 ≤ 0
  7. x² − 9x − 1 ≥ 0
  8. x² − 4xx + 2 < 0

Сначала приведите к стандартному виду, затем решите

  1. (x − 2)(x + 3) > 4
  2. (2x − 1)(x + 2) ≤ x + 7
  3. x + 1x − 2 − 1 > 0
  4. 2xx + 3 + 1 ≤ 0
