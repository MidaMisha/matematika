Показательные уравнения

Показательным называется уравнение, в котором неизвестная находится в показателе степени. Главная идея решения: преобразовать степени к удобному виду, а затем применить один из типовых методов.

1. Равенство степеней с одинаковым основанием

Если a > 0, a ≠ 1 и af(x) = ag(x), то f(x) = g(x).
Пример 1. Решить 52x−1 = 5x+3.
Уравниваем показатели: 2x − 1 = x + 3, откуда x = 4.
Ответ: 4.
Уравнивать показатели можно только после того, как основания степеней стали одинаковыми.

2. Приведение к одному основанию

Числа часто можно представить степенями одного основания:

4 = 22, 8 = 23, 16 = 24;   9 = 32, 27 = 33, 81 = 34.
Пример 2. 4x+1 = 82x−1.
22(x+1) = 23(2x−1).
2x + 2 = 6x − 3, поэтому 4x = 5 и x = 5/4.
Ответ: 5/4.

3. Вынесение общего множителя

Если показатели отличаются на постоянное число, одну степень удобно выразить через другую.

Пример 3. 3x+1 + 3x = 108.
3 · 3x + 3x = 108.
4 · 3x = 108, поэтому 3x = 27 = 33.
Ответ: 3.

4. Замена переменной

Если в уравнении встречаются a2x, ax и число, вводят замену t = ax. При этом обязательно t > 0.

Пример 4. 4x − 5 · 2x + 4 = 0.
Пусть t = 2x, t > 0. Тогда 4x = 22x = t2.
t2 − 5t + 4 = 0; t = 1 или t = 4.
2x = 1 ⇒ x = 0;   2x = 4 ⇒ x = 2.
Ответ: 0; 2.

5. Деление на положительное выражение

Степень с положительным основанием всегда положительна, поэтому на неё можно делить обе части уравнения.

Пример 5. 2 · 9x − 5 · 6x + 3 · 4x = 0.
Делим на 4x > 0:
2(9/4)x − 5(3/2)x + 3 = 0.
Пусть t = (3/2)x. Тогда 2t2 − 5t + 3 = 0.
t = 1 или t = 3/2. Получаем x = 0 или x = 1.
Ответ: 0; 1.

6. Функционально-графический метод

Если одна часть уравнения возрастает, а другая убывает, то уравнение имеет не более одного корня. Найденный подбором корень в таком случае является единственным.

Пример 6. 2x = 3 − x.
Левая часть возрастает, правая убывает. При x = 1 получаем 2 = 2. Следовательно, других корней нет.
Ответ: 1.

8. Проверочный алгоритм

  1. Упростить степени и дроби.
  2. Попробовать привести всё к одному основанию.
  3. Проверить, можно ли вынести общую степень.
  4. Если есть квадрат относительно ax, выполнить замену.
  5. Отбросить значения замены, не удовлетворяющие условию t > 0.
  6. Вернуться к переменной x и проверить результат.
