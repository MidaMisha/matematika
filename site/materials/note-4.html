1. Стандартный вид

Квадратное уравнение имеет вид ax² + bx + c = 0, где a ≠ 0. Коэффициенты записывают вместе со знаками. Например, у 3x² − 8x − 2 = 0: a = 3, b = −8, c = −2.

Сначала раскройте скобки, перенесите все слагаемые в одну часть и приведите подобные. Если коэффициент при x² сократился до нуля, уравнение уже не квадратное.

2. Неполные уравнения

ВидКак решать
ax² = 0x = 0.
ax² + bx = 0x(ax + b) = 0: x = 0 или x = −b/a.
ax² + c = 0x² = −c/a. При положительной правой части — два корня, при нулевой — один, при отрицательной — действительных корней нет.

2x² − 32 = 0 → x² = 16 → x = ±4.

3x² + 12 = 0 → x² = −4 → действительных корней нет.

2x² − 10x = 0 → 2x(x − 5) = 0 → x = 0 или x = 5.

Не делите уравнение на x без проверки x = 0: можно потерять корень.

3. Дискриминант

D = b² − 4ac.

  • D > 0: два разных корня x₁ = (−b − √D)/(2a), x₂ = (−b + √D)/(2a).
  • D = 0: один корень x = −b/(2a).
  • D < 0: действительных корней нет.

2x² − 9x + 4 = 0.

D = (−9)² − 4 · 2 · 4 = 81 − 32 = 49.

x₁ = (9 − 7)/4 = 1/2; x₂ = (9 + 7)/4 = 4.

x² − 6x + 9 = 0: D = 36 − 36 = 0, x = 3.

x² + 2x + 5 = 0: D = 4 − 20 = −16, корней нет.

4. Отрицательные и крупные коэффициенты

Можно разделить всё уравнение на общий ненулевой множитель или умножить на −1. Корни от этого не меняются.

−4x² + 14x − 6 = 0. Делим на −2:

2x² − 7x + 3 = 0. D = 49 − 24 = 25.

x = (7 ± 5)/4, то есть 1/2 и 3.

В формуле знаменатель — всё выражение 2a. Квадрат отрицательного числа положителен: (−7)² = 49.

5. Сначала упростить

(x − 1)(x + 4) = 6.

x² + 3x − 4 = 6 → x² + 3x − 10 = 0.

D = 9 + 40 = 49 → x = (−3 ± 7)/2.

Ответ: x = 2 или x = −5.

Нужные формулы: (a + b)² = a² + 2ab + b²; (a − b)² = a² − 2ab + b²; (a − b)(a + b) = a² − b².

6. Теорема Виета и проверка

Для x² + px + q = 0 сумма корней равна −p, произведение — q. Для общего вида сумма равна −b/a, произведение — c/a.

x² − 8x + 15 = 0. Числа 3 и 5 дают сумму 8 и произведение 15, значит это корни.

Памятка: стандартный вид → коэффициенты со знаками → D → корни → проверка.
