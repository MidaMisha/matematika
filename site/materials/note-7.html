1. Что означает корень

Корень n-й степени из a — число, n-я степень которого равна a. В записи ⁿ√a число n ≥ 2 — натуральный показатель корня, a — подкоренное выражение.

Для чётного n арифметический корень определён при a ≥ 0 и выбирается неотрицательным. Для нечётного n корень существует при любом действительном a.

√169 = 13, потому что 13² = 169.

∛(−343) = −7, потому что (−7)³ = −343.

∜256 = 4, потому что 4⁴ = 256.

√(−9) в действительных числах не определён.

√36 = 6, а уравнение x² = 36 имеет два корня: x = ±6. Это разные задачи.

2. Произведение и частное

ⁿ√(ab) = ⁿ√a · ⁿ√b. Для чётного n используем это свойство при a ≥ 0, b ≥ 0; для нечётного — при любых действительных a и b.

ⁿ√(a/b) = ⁿ√a / ⁿ√b. Для чётного n: a ≥ 0, b > 0; для нечётного: b ≠ 0.

√(16 · 49) = 4 · 7 = 28.

∛(27 · 125) = 3 · 5 = 15.

√(25/144) = 5/12; ∛(8/343) = 2/7.

3. Вынесение множителя из-под корня

Выделите под корнем множитель, который является полной n-й степенью.

√80 = √(16 · 5) = 4√5.

∛81 = ∛(27 · 3) = 3∛3.

∜112 = ∜(16 · 7) = 2∜7.

Чем выше показатель корня, тем большую степень нужно выделить: для квадратного — квадрат, для кубического — куб.

4. Внесение множителя под корень

Для чётного n и c ≥ 0: c · ⁿ√a = ⁿ√(cⁿa). Отрицательный внешний множитель оставляют перед чётным корнем. Для нечётного n множитель можно вносить вместе со знаком.

2√11 = √(4 · 11) = √44.

4∛3 = ∛(64 · 3) = ∛192.

−3√2 = −√18, но не √18.

5. Упрощение выражений

Складывать коэффициенты можно только у одинаковых корней. Сначала вынесите множители.

3√20 + √45 = 3 · 2√5 + 3√5 = 9√5.

2∛24 − ∛81 = 4∛3 − 3∛3 = ∛3.

√6 · √24 = √144 = 12.

∛40 : ∛5 = ∛8 = 2.

√(a + b) обычно не равно √a + √b. Например, √(9 + 16) = 5, а √9 + √16 = 7.

6. Корень из степени и модуль

√(x²) = |x|; ∜(x⁴) = |x|; ∛(x³) = x.

Для чётного показателя результат должен быть неотрицательным, поэтому появляется модуль. Для нечётного знак сохраняется.

√((−11)²) = 11.

√(36x²) = 6|x|. Если x ≥ 0, это 6x; если x < 0, это −6x.

∜(81a⁴) = 3|a|; при a ≥ 0 получаем 3a.

∛(64x³) = 4x при любом действительном x.

Обратное действие: (ⁿ√a)ⁿ = a на области определения корня.

7. Памятка

  1. Проверьте чётность показателя и допустимость выражения.
  2. Ищите полные степени среди множителей.
  3. После упрощения объединяйте только одинаковые корни.
  4. В корне чётной степени из такой же степени переменной не забывайте модуль.
