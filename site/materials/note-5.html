1. Линейные неравенства

Перенос слагаемых работает так же, как в уравнениях. При умножении или делении обеих частей на отрицательное число знак неравенства меняется на противоположный.

9 − 3x > 15 → −3x > 6 → x < −2.

Ответ: (−∞; −2).

Круглая скобка означает, что граница не включена; квадратная — включена. Возле ±∞ всегда ставят круглую скобку.

2. Алгоритм метода интервалов

  1. Перенесите всё в одну часть, чтобы справа был 0.
  2. Разложите числитель и знаменатель на множители.
  3. Найдите нули числителя и знаменателя, отметьте их по возрастанию.
  4. Определите знак выражения на каждом промежутке подстановкой пробного числа.
  5. Выберите промежутки с нужным знаком.
  6. При ≤ или ≥ включите допустимые нули числителя. Нули знаменателя исключаются всегда.

Через корень нечётной кратности знак меняется, через корень чётной кратности — сохраняется. Если сомневаетесь, подставляйте пробные числа.

3. Произведение с тремя и четырьмя точками

(x + 2)(x − 2)(x − 5) > 0.

Точки: −2, 2, 5. Справа от 5 все множители положительны. Все корни простые, поэтому знаки чередуются.

ИнтервалЗнак
(−∞; −2)−
(−2; 2)+
(2; 5)−
(5; +∞)+

Ответ: (−2; 2) ∪ (5; +∞).

(x + 4)(x + 1)(x − 2)(x − 7) ≤ 0.

Точки −4, −1, 2, 7. Знаки слева направо: +, −, +, −, +.

Ответ: [−4; −1] ∪ [2; 7]. Корни включены, потому что знак нестрогий.

4. Квадратное неравенство

Найдите корни квадратного трёхчлена. При a > 0 и двух разных корнях он положителен снаружи корней и отрицателен между ними. При a < 0 знаки противоположны.

x² − 6x + 8 ≤ 0 → (x − 2)(x − 4) ≤ 0.

Ответ: [2; 4].

−x² + 5x − 4 > 0. Умножаем на −1 и меняем знак:

x² − 5x + 4 < 0 → (x − 1)(x − 4) < 0 → x ∈ (1; 4).

Если D < 0, знак трёхчлена всюду совпадает со знаком a. Если D = 0, трёхчлен имеет вид a(x − x₀)²: знак вне корня одинаков с обеих сторон, в корне значение 0.

5. Дробно-рациональное неравенство

(x − 2)/(x + 3) ≤ 0. ОДЗ: x ≠ −3.

Точки: −3 (знаменатель) и 2 (числитель).

При x = −4 дробь положительна; при x = 0 отрицательна; при x = 3 положительна.

Ответ: (−3; 2]. Точка −3 исключена, 2 включена.

Нельзя просто умножить неравенство на x + 3: его знак зависит от x. Безопаснее использовать метод интервалов.

(x − 1)²/(x + 2) > 0.

Числитель положителен всюду, кроме x = 1; знак дроби определяется знаменателем. При x = 1 дробь равна нулю.

Ответ: (−2; 1) ∪ (1; +∞).

6. Приведение к стандартному виду

(x + 2)/(x − 3) − 1 > 0.

Приводим к общему знаменателю: (x + 2 − (x − 3))/(x − 3) > 0.

5/(x − 3) > 0. Числитель положителен, значит x − 3 > 0.

Ответ: (3; +∞).

Памятка: справа 0 → критические точки → знаки → границы → ответ.
